# RingClaw

RingCentral AI Agent 桥接器

将 RingCentral Team Messaging 接入 AI Agent — Claude、Codex、Gemini、Kimi 等。

[快速开始](/zh/guide/getting-started){.action-btn .primary}

## 功能特性

<div class="features-grid">

<div class="feature">

### 🤖 多 Agent 支持

接入 Claude、Codex、Gemini、Kimi、Copilot、Droid 等。一条命令切换 Agent。支持 ACP、CLI、HTTP 三种模式。

</div>

<div class="feature">

### 🔒 安全优先

三层权限模型：可信发送者 allowlist、聊天命令授权、ACP 会话能力门控（`/full-access` 两步审批）。内置 Token 认证、DNS 重绑定防护、工作目录路径限制。

</div>

<div class="feature">

### 💬 聊天总结

总结任意聊天的对话内容。按名称解析目标，获取消息，AI 生成摘要发送到当前聊天。

</div>

<div class="feature">

### ⚡ AI 驱动操作

Agent 在对话中自动创建笔记、任务、日历事件和 Adaptive Card。无需额外配置。

</div>

<div class="feature">

### ⏰ 定时任务与心跳

使用 Cron 表达式或固定间隔调度任务。心跳模式基于用户编写的检查清单定时执行 Agent 巡检。

</div>

<div class="feature">

### 🖥️ 完整 CLI

完整的命令行工具，支持消息、聊天、任务、笔记、事件、卡片、用户和文件操作 — 无需启动 Bridge。

</div>

</div>
